# Hub Diagnostics is now Hub Inspector

The app was renamed and moved to [HubInspector](../HubInspector/README.md).

`HubDiagnostics.groovy` in this folder is kept so installs that import from this URL still receive updates. Importing it once switches the app to the new location. Your settings, history and dashboard link carry over.
